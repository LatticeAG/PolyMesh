# create-polymesh-app

Create a minimal local PolyMesh project:

```sh
npx @latticeag/create-polymesh-app my-agents
cd my-agents
npm install
npm run demo
```

The generated project uses the published `@latticeag/polymesh-broker` and
`@latticeag/polymesh-client` packages and demonstrates a token-protected,
numeric-loopback ping/pong exchange.
